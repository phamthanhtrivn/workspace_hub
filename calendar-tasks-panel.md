# Calendar Tasks Panel

## Goal

Add a Calendar-native task drawer inspired by Google Tasks, separating personal Calendar tasks from read-only project tasks.

## Tasks

- [x] Add a paginated API for all user-managed Calendar tasks.
- [x] Add frontend query and task grouping utilities.
- [x] Build the responsive task drawer and completed section.
- [x] Separate personal and project tasks into dedicated tabs.
- [x] Keep project tasks read-only until Project Service synchronization is connected.
- [x] Keep sidebar visibility, drawer, and color controls independent.
- [x] Add regression tests and run validation.

## Done When

- [x] Clicking the Tasks label opens the drawer; users can complete personal tasks and inspect read-only project tasks without leaving Calendar.
