# Calendar Tasks Panel

## Goal
Add a Calendar-native task drawer inspired by Google Tasks while reusing Calendar TASK events and existing mutations.

## Tasks
- [ ] Add a paginated API for all user-managed Calendar tasks.
- [ ] Add frontend query and task grouping utilities.
- [ ] Build the responsive task drawer and completed section.
- [ ] Open the task form directly in TASK mode.
- [ ] Keep sidebar visibility, drawer, and color controls independent.
- [ ] Add regression tests and run validation.

## Done When
- [ ] Clicking the Tasks label opens the drawer, and users can add, inspect, complete, reopen, and review tasks without leaving Calendar.
