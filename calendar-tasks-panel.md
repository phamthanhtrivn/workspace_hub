# Calendar Tasks Panel

## Goal

Add a Calendar-native task drawer inspired by Google Tasks while reusing Calendar TASK events and existing mutations.

## Tasks

- [x] Add a paginated API for all user-managed Calendar tasks.
- [x] Add frontend query and task grouping utilities.
- [x] Build the responsive task drawer and completed section.
- [x] Open the task form directly in TASK mode.
- [x] Keep sidebar visibility, drawer, and color controls independent.
- [x] Add regression tests and run validation.

## Done When

- [x] Clicking the Tasks label opens the drawer, and users can add, inspect, complete, reopen, and review tasks without leaving Calendar.
