# Workspace module responsive audit

Source audit: 2026-10-18. This inventory covers every TSX file under Calendar, Pomodoro, Chat, Meeting and Documents, plus the entry points and shared layout dependencies below. A kept file was reviewed for sizing ownership; kept does not mean every runtime branch was exercised.

## Layout contract

- Full available content width with existing 16/24/32px page gutters; centered focus/media/dialog limits remain intentional.
- Calendar navigation uses its 960px workspace breakpoint; Tasks is inline only when the calendar canvas reaches 1040px (400px Tasks + 640px calendar).
- Messages uses 720px for sidebar + conversation and 1060px for an inline 340px information/thread panel. Compact panels overlay; the chat subtree stays mounted on resize.
- Documents navigation becomes a side column at 960px; Details is inline at 800px canvas width. File grids measure the remaining file-list width.
- Meetings navigation uses 1120px module width. Room panels are inline at 1060px; compact panels cover the stage while call controls remain available.
- Deep focus stays centered. Full Pomodoro uses two columns above 880px available width.
- Viewport-positioned calendar dialogs and message menus portal to document.body so container containment cannot offset or clip them.
- The new dialog CSS module is opt-in; shared dialog defaults and unrelated pages are not restyled.

## Verification boundaries

- Source sizing/scroll review covers all inventory rows and their static import owners, including helpers and delegated wrappers.
- Loading, empty, error, pending/disabled and populated branches were inspected in source; no network mutations are needed for this change.
- TypeScript: `tsc --noEmit --incremental false` passed. ESLint checked 126 changed TS/TSX sources: 133 existing errors and 51 existing warnings, zero introduced errors/warnings compared with HEAD (embedded line-number changes normalized). Existing debt was not refactored during responsive work.
- Browser/interaction checks were not run: the final browser inventory returned no apps or browsers. Mobile/desktop rendering, touch gestures, camera/microphone behavior and real drag/resize remain unverified at runtime. No testing package, temporary test suite or npm cache was added.
- Representative container-query/intrinsic-grid utilities compile with the installed Tailwind version in memory. The mechanical style scan reported only the existing message-formatter blockquote border, which is an intentional content-formatting exception in DESIGN.md.
